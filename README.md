# 星屑クエスト 〜ルミナと森の魔王〜 v2

スマホ横画面専用の2D JRPG。単一HTMLファイル、外部アセットなし。

v2: 全5章の長編ストーリー、仲間モンスター24種（ほし玉で捕獲、パーティ戦）、星屑ガチャ（確率明示・30連天井）、ジェム経済とデモ課金ショップ、実績・デイリー依頼。実マネタイズ設計は MONETIZATION.md。

## 遊び方
- ブラウザで index.html を開き、スマホを横にする
- 左下スティックで移動、A=調べる/決定、B=キャンセル/ダッシュ（PC: WASD/矢印、Z=決定、X=キャンセル、Shift=ダッシュ）
- 村で長老の話を聞く → 星屑の森で星の欠片 → 洞窟の最奥で魔王ガルドラ戦
- 1プレイ約15〜25分。セーブは自動＋メニューから手動（ブラウザ保存）
